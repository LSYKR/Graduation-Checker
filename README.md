# 🎓 졸업나침반 | GradCompass

> **성적표 한 장으로, 졸업까지 남은 요건과 확인할 항목을.**

입학년도·전공·성적표를 적용 가능한 교육과정 규칙과 대조해 **졸업 준비도, 부족 학점, 미이수 과목, 확인이 필요한 항목**을 보여주는 웹서비스입니다. 한국해양대학교의 공식 졸업 판정을 대신하지 않습니다.

[📘 상세 프로젝트 문서](https://app.notion.com/p/In-Progress-3c30dab1221280678ea1f9d1f048e79e)

## 핵심 기능

- 한국해양대학교 종합정보시스템 성적표 Excel을 브라우저에서 분석
- 교과목번호와 공식 자료의 적용 범위를 기준으로 전공·교양 이수 대조
- 입학년도·전공별 졸업요건을 정확한 규칙 키로 선택
- 대체 인정 확인 항목과 초과학점의 일반선택 이관을 구분
- 다른 전공 성적표의 오적용과 근거가 부족한 확정 판정을 방지
- 부족 학점·미이수 과목을 표시하고, 대화창의 자연어 요청으로 2026-2 시간표와 원하는 요일의 공강 우선 대안을 생성

## 동작 방식

```text
학생 정보 입력 → 성적표 업로드 → 적용 규칙 대조 → 남은 요건 확인 → 시간표·공강 조건 요청
```

졸업요건 계산은 LLM의 추측이 아닌 **결정형 규칙 엔진**이 수행합니다. 근거가 부족한 항목은 임의로 충족 처리하지 않고 `확인 필요` 또는 `판정 보류`로 표시합니다.

로컬 AI 상담 화면에서 “금요일 공강 만들어줘”처럼 요청하면, 확인된 2026-2 개설강좌와 개인 진단 결과를 바탕으로 시간표를 구성합니다. 원하는 공강 요일, 최대 학점, 온라인 수업 허용 여부 등을 반영하고 분반 시간 충돌을 검사합니다. 공강과 졸업요건 후보가 충돌하면 공강 우선 대안과 남은 조건을 함께 보여줍니다. **로컬 LLM은 상담 설명을 보조하고, 분반 선택과 시간표 구성은 결정형 플래너가 수행합니다.**

## Tech Stack

`TypeScript` · `React 19` · `Next.js 16` · `SheetJS` · `Tailwind CSS` · `Docker` · `로컬 LLM(선택)` · `AWS/Terraform`

## 현재 지원 범위

**한국해양대학교 해양과학기술융합대학 · 2020~2026학번 · 신입학/편입학**

> 연도·전공별 상세 과목표와 편입 인정 근거의 검수 수준은 서로 다릅니다. 시간표는 검수·활성화된 2026-2 개설강좌를 사용하며, 실제 수강신청 자격·정원·변경 여부는 별도 확인이 필요합니다.

## 개인정보 원칙

- 성적표 원본은 브라우저 메모리에서 처리하며 서버 업로드 API로 보내지 않습니다.
- 학번·성명 열은 성적표 파서의 과목 결과 모델에 포함하지 않습니다.
- 상담을 사용하면 질문과 제한된 진단 요약이 로컬 앱 서버로 전송됩니다. 질문에 직접 적은 개인정보도 전송 대상입니다.
- 실제 사용자 성적 파일은 이 소스 묶음과 배포물에 포함하지 않습니다.
- 최종 졸업 가능 여부는 학사과 또는 학과사무실의 공식 확인이 필요합니다.

## 실행 및 검증

Node.js 24.18.0이 필요합니다. 기본 설정에서는 LLM 없이 실행됩니다.

```bash
npm ci --ignore-scripts
cp .env.example .env.local
npm run typecheck
npm run rules:check
npm run build
npm start
```

Windows PowerShell에서는 `Copy-Item .env.example .env.local`을 사용합니다. 실행 주소는 `http://localhost:3000`, 상태 확인은 `/api/health`입니다. 개발 서버는 `npm run dev`, Docker 실행은 `docker compose up --build -d`를 사용합니다. 로컬 모델 설정과 규칙 팩·개설강좌 데이터 관리 방법은 [배포 안내](DEPLOY_PACKAGE.md), [규칙 팩 문서](docs/RULE_PACKS.md), [개설강좌 문서](docs/COURSE_OFFERINGS.md)를 참고하세요.

AWS 배포 코드는 프로젝트 루트의 `terraform/`에서 실행합니다. 서울 리전의 단일 EC2와 ECR, HTTPS용 Caddy, SSM 접근, 외부 로컬 LLM 연결용 WireGuard를 구성합니다. 도메인과 WireGuard 설정을 저장한 SSM SecureString을 먼저 준비해야 하며, Terraform 코드의 실제 `plan/apply`와 AWS 배포는 아직 이 검토에서 실행하지 않았습니다.

2. **한국해양대학교 전체 학과 적용**

3. **다른 대학교로 확장**
