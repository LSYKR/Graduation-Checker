# Model Card: GradCompass-KMOU Router

## 개요

- 베이스 모델 후보: Qwen2.5-3B-Instruct
- 방법: 4-bit NF4 QLoRA, rank 16
- 목적: 졸업 상담 질문의 의도분류, 도구 선택, 근거 필요성 출력
- 언어: 한국어 중심
- 상태: 선택 학습 실험. 배포 데모는 결정형 fallback을 사용함

## 의도된 사용

학생의 질문을 audit, course-planning, certification, early-graduation 중 하나로 분류하고 호출할 도구를 JSON으로 제안한다. 공식 문서 검색과 규칙 엔진 결과를 자연어로 설명하는 보조 모델로 사용할 수 있다.

## 금지된 사용

- 모델 단독으로 졸업 가능 여부 확정
- 공식 규칙 없이 학점·인증 기준 생성
- 학생 성적 원문이나 학번을 학습 데이터로 저장
- 학사과 또는 학과사무실의 최종 졸업사정 대체

## 데이터

현재 저장소에는 비식별 합성 의도 예시만 포함한다. 실제 성적은 학습 데이터로 사용하지 않는다. 향후 데이터 확장 시 담당자의 검수와 개인정보 영향평가가 필요하다.

## 평가

- 의도별 도구 선택 exact match
- JSON 형식 유효성
- 검색 근거 인용률
- 도구 결과와 생성 설명의 수치 일치
- 확정적·과장된 표현 비율

## 한계

훈련 예시가 적어 표현 다양성과 학과별 전문용어에 취약할 수 있다. 규칙이 바뀌면 모델을 재학습하는 대신 지식베이스와 규칙셋을 갱신해야 한다.
