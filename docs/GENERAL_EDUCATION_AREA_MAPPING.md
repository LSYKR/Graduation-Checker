# 한국해양대학교 컴퓨터공학 계열 교양 세부영역 매핑

## 목적

성적표의 교양선택 총학점만 합산하지 않고, 입학년도별 공식 교양교육 이수체계와 교양과목 편람을 함께 사용해 사회·경제, 역사·문화, 해양 영역의 충족 여부를 결정형으로 계산한다.

2022학번 컴퓨터공학 범위의 교양 세부영역 코드 맵과 특수 인정 오버레이는 원본·해시·셀 위치를 고정한 `verified-final` 범위로 운영한다. 그 밖의 졸업요건과 다른 학번의 운영 활성화는 별도 승인 전까지 제한한다.

## 학번별 후보 기준

| 학번 | 개별 최소학점 | 결합 최소학점 |
| --- | --- | --- |
| 2020 | 해양과 문화 2, 해양 스포츠와 예술 2, 역사와 문화 3, 사회와 경제 3 | 역사와 문화 + 사회와 경제 합계 8 |
| 2021~2024 | 해양과 문화 2, 해양 스포츠와 예술 2, 역사와 문화 4, 사회와 경제 4 | 역사와 문화 + 사회와 경제 합계 9 |
| 2025~2026 | 해양기초 선택교양 2 | 없음 |

2025학번부터는 교양 체계가 개편됐으므로 2020~2024학번의 사회·경제 및 역사·문화 개별 최소학점 규칙을 임의로 상속하지 않는다.

## 과목 매핑 정책

- 공식 교양과목 편람의 교과목번호와 성적표 교과목번호가 정확히 일치할 때만 영역 과목으로 인정한다.
- 기본 교양과목표에 없는 이중설강·교차강의는 학과별 공식 이수체계표에 코드와 인정 유형이 명시된 경우에만 별도 오버레이로 인정한다.
- 특수 인정 오버레이는 `학교 + 입학학년도 + 학과` 정확 키에만 결합하며 다른 학번·학과로 상속하지 않는다.
- `편입생 인정학점` 행도 공식 교과목번호가 정확히 일치하고 해당 오버레이가 편입 인정행을 허용할 때만 합산한다.
- 과목명 유사도, 키워드, LLM 추측으로 영역을 인정하지 않는다.
- 과목명이 같아도 코드가 다르면 자동 인정하지 않는다.
- 공식 목록에 없는 교양선택 과목이 존재하고 해당 영역이 부족하면 `미충족`으로 확정하지 않고 `확인 필요`로 표시한다.
- 여러 영역 결합 최소학점 계산에서는 동일 과목을 한 번만 합산한다.
- 하나의 코드가 여러 영역에 동시에 매핑되거나 존재하지 않는 영역을 참조하면 자동 합산하지 않고 `확인 필요`로 중단한다.
- 이중설강의 영역 인정과 성적표 이수구분 총학점 재분류는 분리한다. 개인별 이수구분은 성적표 원값을 보존한다.

## 데이터 위치

- 학번별 통합 과목코드 맵: `data/extracted/kmou/general-education-area-map-2020-2026.json`
- 2022 컴퓨터공학 특수 인정 오버레이: `data/policy-overlays/kmou/general-education/2022/computer-engineering/1.0.0.json`
- 특수 인정 오버레이 JSON Schema: `schemas/general-education-recognition-overlay.schema.json`
- 적용 교육과정별 공통 규칙 후보: `data/rule-candidates/kmou/<year>/computer-engineering/curriculum/0.2.0.json`
- 공식 원본 및 해시: `data/sources/kmou/source-manifest.json`
- 결정형 판정 엔진: `lib/general-education-engine.ts`

## 판정 결과 상태

| 상태 | 의미 |
| --- | --- |
| `satisfied` | 공식 과목코드로 최소학점을 충족함 |
| `missing` | 모든 교양선택이 매핑되었고 최소학점이 부족함 |
| `needs-review` | 미매핑 교양선택이 있어 부족 여부를 확정할 수 없음 |
| `not-evaluable` | 공식 과목 목록 또는 규칙 자체가 불완전함 |

## 승인 전 확인해야 할 항목

1. 학년도별 교양교육 이수체계의 페이지와 최소학점 재대조
2. 학년도별 교양과목 편람의 영역·소영역·교과목번호 재대조
3. 폐지·교과목번호 변경·동일교과목 인정표 확인
4. 개인별 이수구분 재분류가 필요한 경우 종합정보시스템의 개인별 교양 이수판정과 대조
5. 관리자 승인자와 승인 시각 기록

이 조건을 충족하기 전에는 운영 규칙 레지스트리에 등록하지 않는다.
