# 6분 시연 대본

## 0:00–0:40 문제와 대상

“졸업요건은 총학점만 확인하면 끝나는 문제가 아닙니다. 저희 MVP는 한국해양대학교 2022학번 컴퓨터공학과 편입생을 대상으로 실제 성적 파일과 공식 교육과정을 비교합니다.”

## 0:40–1:40 성적표 업로드

1. 왼쪽 `성적표 업로드` 선택
2. 프로필이 2022·컴퓨터공학과·편입생인지 확인
3. 실제 Excel 업로드
4. “50개 행, 133학점, 5개 재분류” 결과 강조
5. “파일은 서버로 보내지 않는다”는 개인정보 설계 설명

## 1:40–2:35 졸업 진단

1. `진단 결과 확인` 선택
2. 영역별 24/26, 19/17, 16/15, 51/60, 8/12, 15/10 확인
3. 필수 12학점 + 전공선택 6학점 계획 설명
4. 공식 교육과정·교양·졸업인증 링크 제시

## 2:35–3:35 AI 상담

1. `AI 졸업 상담` 선택
2. “편입생도 조기졸업할 수 있어?” 클릭
3. explainRequirement 도구와 교육과정 인용 강조
4. “다음 학기 과목을 추천해줘” 클릭
5. auditGraduation + recommendCourses 도구 호출 강조

## 3:35–4:20 수강 설계

1. `수강 설계` 선택
2. 필수과목과 전공선택 후보를 토글
3. 금요일 공강 선호 확인
4. 실제 분반 공개 전에는 후보 추천이며, 학과 확인 항목이 분리됨을 설명

## 4:20–5:10 운영·확장

1. `요건 데이터` 선택
2. 원본, 구조화 규칙, override를 분리한 구조 설명
3. university → year → department → studentType 확장 키 제시

## 5:10–6:00 모델·평가

1. `모델 · 평가` 선택
2. RAG → LLM → 도구 → 근거 응답 파이프라인 설명
3. 규칙 6/6, 의도 12/12, 개인정보 4/4 결과
4. QLoRA는 선택 실험, 현재 데모는 결정형 fallback임을 명확히 구분
5. “LLM이 졸업을 판정하는 것이 아니라 검증된 판정을 설명한다”로 마무리
