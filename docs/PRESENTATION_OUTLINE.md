# 기말발표 구성안 (12장)

## 1. 제목

- 졸업나침반: 근거 기반 졸업요건 진단 LLM 서비스
- 팀원, 과목명, 지도교수

## 2. 문제

- 졸업요건이 입학년도·학과·학생유형별로 분산
- 총학점 충족만으로 졸업할 수 없음
- 잘못 해석하면 한 학기 이상 졸업 지연

## 3. 사용자 시나리오

- 2022학번 컴퓨터공학과 편입생
- 종합정보시스템 Excel 업로드
- 부족한 과목·인증 확인
- 다음 학기 18학점 계획 생성

## 4. 실제 데이터 형식

- 11개 열, 50개 교과목 행
- 편입 인정학점, 영문·숫자 과목코드, 0학점 필수
- 개인정보를 제외하고 브라우저에서 파싱

## 5. 전체 아키텍처

- 공식 문서 → 규칙·RAG 지식베이스
- 성적 Excel → 클라이언트 파서 → 규칙 엔진
- 질문 → LLM → 도구 호출 → 근거 포함 응답

## 6. 규칙 엔진 데모

- 총 133학점
- 교필 24, 교선 19, 전기 16, 전필 51, 전선 8, 일선 15
- 교과목 분류 보정과 대체과목 처리

## 7. RAG

- 입학년도·학과·학생유형 메타데이터 필터
- 교육과정, 교양, 졸업인증 문서 검색
- 원문 URL과 관련도 표시

## 8. Agent와 도구 호출

- auditGraduation
- recommendCourses
- checkCertification
- explainRequirement
- 학점 계산은 LLM이 수행하지 않음

## 9. PEFT·서빙

- Qwen2.5-3B-Instruct + 4-bit QLoRA 실험안
- 의도분류·근거 설명만 학습
- 결정형 fallback으로 네트워크 없이 안정적 데모

## 10. 평가 결과

- 규칙 6/6
- 실제 파일 6개 영역 일치
- 의도·도구 12/12
- 개인정보 4/4

## 11. Responsible AI

- 공식 근거와 규칙 버전
- 조건부 판정·학과 확인
- 파일 로컬 처리, 식별 열 제거
- 최종 졸업사정 면책

## 12. 결론·확장

- 지능제어전공 → 다른 학번 → 다른 대학
- 수강편람 연동과 시간표 최적화
- 질의응답 및 시연 URL
