# 운영 규칙 Trust Gate

졸업 판정은 아래 조건을 모두 충족해야 열린다.

1. 공통 졸업요건은 `universityId + admissionYear + departmentId + curriculumTrack`가 정확히 일치하고, 학생 유형별 정책은 별도 오버레이의 키가 정확히 일치한다.
2. 조회 결과가 승인 규칙 정확히 1개다. 0개 또는 2개 이상이면 중단한다.
3. 총학점·영역별 학점·필수과목·교양체계·졸업인증의 원본이 공식 도메인에 존재한다.
4. 판정에 사용한 모든 첨부파일이 로컬 원본 저장소에 있고 SHA-256으로 고정되어 있다.
5. 편입생은 동일 공통 졸업요건에 성적표의 편입 인정행을 결합하며, 편입연도별 정책과 개인 인정내역을 분리한다.
6. 성적표 필수 열과 학교 양식이 완전히 인식된다. 미분류 과목이 임계치를 넘으면 중단한다.
7. 대체과목은 `confirmed / conditional / missing`을 구분한다.
8. 교양 세부영역은 기본 교양표와 학과별 이중설강·교차강의 오버레이를 분리하고, 둘 다 공식 교과목번호 정확 일치만 허용한다.
9. 특수 인정 오버레이는 대학·학번·학과 범위, 원본 SHA-256, 시트·셀 범위, 인정 유형을 고정한다.
10. 동일 코드는 한 번만 합산하며 여러 영역 충돌·존재하지 않는 영역 참조·미매핑 코드는 자동 판정하지 않는다.
11. 판정 엔진 버전이 바뀌면 원본 성적표가 없는 과거 브라우저 캐시 결과를 재사용하지 않고 재업로드를 요구한다.
12. 관리자 승인과 감사 로그가 존재한다.

현재 2022 컴퓨터공학의 교양 세부영역과 특수 인정 오버레이만 검증 완료 범위로 활성화했다. 필수과목·대체과목·졸업인증 등 나머지 범위는 임시 판정이며 최종 졸업사정을 대체하지 않는다.
